# Docker Hosting Guides

A collection of practical Docker hosting, installation and container management guides for VPS, VDS and dedicated servers.

## About This Repository

This repository provides educational resources for system administrators, developers and users interested in deploying and managing containerized applications on Linux and Windows.

## Docker Guides

| Guide | Description |
|---|---|
| [Docker General Guide](./docker-guide.md) | Docker fundamentals, hosting requirements and server selection. |
| [Docker on Linux](./docker-linux.md) | Docker installation on Ubuntu, Debian, CentOS, Fedora and RHEL. |
| [Docker on Windows](./docker-windows.md) | Docker installation on Windows Server, Windows 10 and 11. |
| [Docker & Portainer](./docker-portainer.md) | Container management through the Portainer web interface. |

## Topics Covered

- Docker Engine and Docker Compose
- Containerization and virtualization
- VPS, VDS and dedicated server hosting
- Linux and Windows environments
- Container security and maintenance
- Portainer management
